# 开头
- 项目开始时间, 请看[内部初版修改开始时间图](./内部初版修改开始时间图.png)

```
基于原poc库里的ob代码开发，AI辅助并人工对其修正，并通过监测游戏提交数据来对比修改，依赖库升级到net10...
尽量在不改动ob代码情况下，使用结果mapping的方式返回给客户端.
下载(bd)：/s/1e-Hjw2Edb-54XlAxWiLwcQ?pwd=djyx

data里的json文件为页面基础数据，感谢各路群友整理!!
不带图包，图包请自行另外下载...
```

* 对应游戏1.04，刷卡默认地址：‘http://127.0.0.1:28080’
* 如果你同时也游玩OB或者有多款ib刷卡，为避免刷卡页面冲突，那么你需要在‘kestrel.json’里改端口..

## 截至当前版本 总功能 简述
- 有些配置在刷卡页面，有些在自定义配置(server.json内有详细说明，设置后需要重启刷卡, 部分配置也需要重启Lm和pcb)
- 本刷卡侧重单机，有些配置也是为单机准备的，不过对战功能也有一定支持.
- 某些配置上手或有难度，需要一定的动手能力，所以要根据自身情况量力而行...
```
* 基本
  1.(对战UI好像可用) 手柄，通信，对战壁纸，机体姿势等对战高度相关的，未改动，未测试，暂无打算...
  2.修正开卡刷卡，对战结果(街机|店内|店外|活动fes)有限保存(包括等级经验/机体熟练度/导航员好感度等)
  3.支持选ib新领航员，新bgm，新ib机体+修正几台机体的cost值+驾驶员皮肤
  4.加载训练场新设置, 但是游戏内不提供保存..
  5.加载偏好机体可配置觉醒和单独的歌曲. server.json可配置偏好机体最大上限(默认12), 刷卡页和游戏里同时能生效。
  6.修正用户等级为1到999到无限
  7.去掉刷卡页面的V觉（包括统计），C觉改为E觉，去掉新卡第2次进教学的提示
  8.server.json里，原ob的配置未改动，新增可指定数据库文件位置
  9.server.json里可配置，刷卡时显示蓝色的‘PLv.プーストキャンペーン開催中!’，显示橙色的‘グルーブボイント 超ブースト中!’(游戏中均没实际效果)
  10.因为ib不区分ui和战斗导航员，刷卡页面里ui导航员和战斗导航员选择后保持一致
  11.去掉原ob活动fes的被禁用的机体
  12.数据库文件回退到ob功能，回退后改名，可迁移到其他魔改ob系列刷卡..(会丢失一点点ib新数据)(详情请查看1.2.0更新)
  13.你猜猜在哪里的防倒卖信息...

* 街机模式 (详情请查看1.1.2和1.2.2更新)
  1.刷卡后可正常预先选难度5。后续游戏新版本的新难度需要打过旧难度才会开启。
  2.stage通关后可中断再开。再开后第一局小关卡结算前可按test重启再再开(每次再开都是随机路线包括boss)
  3.存档保存在‘Game Over’时才真正保存，不要过早按test键..
  4.server.json可配置, 异常显示stage3和难度10+，不过不能连战，也不能中断再开...

* 快速启动
  1.游戏内支持快速启动加载和保存(暂不支持练习模式和训练场)
  2.刷卡页面支持自定义修改，关闭也支持
  3.注意：不正确的配置可能会使游戏闪退..

* 对战记录页面-修复与优化
  1.修复对战记录觉醒数不算全觉的问题
  2.对战记录页面与原ob关卡页面对换顺序，这样刷卡后点右边按钮直接查看对战记录
  3.对战记录页面加强对外部玩家的判断，尽量避免跨服对战时因相同的用户id而导致查看报错.
  4.选择了中文或英文的时候，对战记录页面里面的时间显示修改为24h制.
  5.server.json可配置, 支持对战结算是否记录cpu的数据
  6.区分是否店外，店外会显示店外等级，其他对战会显示徽章，已实现功能, 但是需要图而我没有...
  7.优化对战记录页面某些机体在没驾驶员时，信息错位的问题...

* 店外经验 (详情请查看1.3.4更新)
  1.根据官网图徽章在店外有经验，尝试支持徽章经验和升级，因为是实验功能，所以同时保留刷卡页可选择徽章(不显示玩家等级在选徽章选项里)
  2.server.json可配置, 支持是否打开店外排位经验。关闭时可自定义段位等级，开启后刷卡加载结算保存
  3.每段每级1000经验,升级有小保质期,避免出现刚升级后反复降级升级的情况..
  4.没实现对战次数等统计信息, 也没实现对战匹配规则, 所以要玩真人店外还是要到群服里去玩的..

* 自定义对战(Custom Match)与(简易)Room (详情请查看1.3.6更新)
  1.自定义对战开启方法：LM开启店外模式+开Room，进入游戏后对战菜单选右上角那个紫色的（替换了原来绿色的混战）..
  2.server.json可配置，支持开启(简易)Room. Room可设置公开/私房，对战时间，限制机体，指定活动fes等..
  3.具体自定义对战有什么不一样，请看官方各对战模式对比图..
  4.开启本地点内外，并选择了自定义对战，是可以连战或GameOver的..只是会卡几秒..
  5.根据room的配置情况，有可能对战记录页面没时间线..LM开启录像功能时，也能记录到包括本地点内外的自定义对战..
  6.LM中选‘カスタムマッチ ル一ム検索’后再刷卡，可以显示房间demo数据(没实际作用)...

  LM可以录像(需要自己设置关店时间)，有一些demo数据，有本刷卡信息...

* 试验功能：远程卡服
  1.server.json里配置, 默认关闭，用于店外对战匹配到群服真人玩家。(如果群服自有支持,为避免冲突,建议不要开启该功能)
  2.不支持连入需要token的群服..
  
* 单人2v2随机人机-另类试验: 本地店内外 (详情请查看1.1.7更新和参考图)
  1.配置过多，需要有一定的计算机知识和动手能力...
  2.需要LM开启店外，需要stun激活，具体看参考图..
  3.此模式在非‘Custom Match’是不能连战的，结算也都会卡一会，结算后会有信息输出到刷卡控制台..
  4.server.json可配置接入‘外部对战匹配规则服务地址’，用于改变现有对战匹配规则..’本地店内外‘其实为该功能的一个特例...
```
