# v1.2.2 更新
```
1.数据库文件回退到ob。如果要使用，记得使用前先备份!!
  使用方法：
    1.记得使用前先备份数据库文件，然后正常打开刷卡页面一次后关闭。
    2.运行‘数据库文件回退到ob_使用前记得备份.bat’, 并按照里面操作提示即可。
  说明：
    1.回退功能会使ib的新字段数据丢失（如训练场新设置）。回退后是ob的数据文件，可在ob环境下游玩...
    2.回退后的数据库文件，理论上可以迁移到其他‘基于魔改ob的ib刷卡服务’版本中，示魔改情度不同，也可能会丢失一点点数据的...
    3.目前本人试过回退后的数据库文件，改名后，可直接在‘Server-Infinite-v1.0’中运行...
  
2.自定义配置 server.json 增加设置几个店外等级

3.试验功能：街机模式中断再开
  说明：
    1.stage过关后弹窗有2个按钮可选择，选左边是连战，选右边是中断。
    2.连战是不保存数据的，中断在出现‘game over’时才真正保存，不要过早按test...
    3.之后刷卡进入街机模式，如有数据可再开，也是弹窗有2个按钮可选择，选左边的会再开，再开后之前的存档就销毁了..
    4.存档是加密数据。好像有时效的，超过时间可能会加载失败..
```

## 截至当前版本 总功能 简述
刷卡及游戏内:
```
1.修正开卡刷卡，对战结果(街机|店内|店外)有限保存(包括等级经验/机体熟练度/导航员好感度等)
2.手柄，通信，对战壁纸，机体姿势等对战高度相关的，未改动，未测试，暂无打算...
3.支持选ib新领航员，新bgm，新ib机体+修正几台机体的cost值+驾驶员皮肤
4.加载训练场新设置
5.加载偏好机体可配置觉醒, 可扩充到12个(游戏内其实可显示16+)
6.修正用户等级为1到999到无限，刷卡页可有限选徽章
7.街机模式刷卡后可正常选难度5，可中断再开(存档有时效的..)
8.去掉刷卡页面的v觉, 去掉新卡第2次进教学的提示
9.数据库文件回退到ob功能，回退后改名，可迁移到其他魔改ob系列刷卡..(会丢失一点点ib新数据)
```
自定义配置(server.json内有详细说明):
```
1.原ob的配置未改动，新增可指定数据库文件位置
2.刷卡时显示蓝色的‘PLv.プーストキャンペーン開催中!’，显示橙色的‘グルーブボイント 超ブースト中!’
3.自定义快速启动，但是游戏内不提供保存..
4.增加设置几个店外等级，店外(段位)样式(即蓝色,金色这些),甚至可显示Ex无限级后的位数(固定了数值)
5.异常显示stage3和难度10+，不过不能连战，也不能中断再开...
6.试验功能：远程卡服，用于店外对战匹配到群服真人玩家。(wippien群自有支持，可无视该功能)
7.单人2v2随机人机-另类试验: 本地店内外..
```
