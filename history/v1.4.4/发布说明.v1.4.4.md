# v1.4.4 更新
```
1.快速启动支持保存练习模式和训练场
2.修正训练场保存现在可以更新配置了...
3.配置文件可配置，是否在保存快速启动时并且gamemode为训练场时，强制保存为单人出击.
  目前发现单人在玩(别的大佬做的)'Training-2v2'时，保存下来的快速启动信息是团体出击的，
  这样下次test重启游戏进入并选择了快速启动后，你就会卡在一个店内选人界面几十秒或无限秒(用了mod)...
  开启此选项后在保存时会强制变成单人，避免出现上述情况...
4.配置文件可配置classmatch的段内level，可根据每段来配置.
  这里的level指的并不是Grade10，Grade9这些...
  指定后配合Match3可实现限制同段同level匹配真人对战(Match3也要相应配置的)...
5.Match3更新，提供api接口，可在不重启情况下，动态修改配置并立即生效...
```
