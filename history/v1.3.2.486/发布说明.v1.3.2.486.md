# v1.3.1.233 更新
```
1.内部代码优化,net10依赖更新到新版
2.因ib不区分ui和战斗导航员，刷卡页面里ui导航员和战斗导航员选择后保持一致
3.刷卡首页文字更新
4.提供容器版stun
5.对战记录页面与原ob关卡页面对换顺序，这样刷卡后点右边按钮直接查看对战记录
6.server.json里面的店外等级更新..
7.尝试支持徽章经验和升级.根据官方图可知，只有店外和街机模式下，才有徽章经验..
  而且徽章与用户等级是不一样的，结算时只提交了对战前的id和输赢exp，不会直接告诉你是否升级了..
  升级的算法在客户端，我也不清楚具体怎样...但实际玩下来发现，包括店内和无论输赢，貌似只要经验到一定值，就会升级(默认不会降级)..
  这里给出一种不太准的方案：
  1.每次对战结算，经验首先先累计
  2.正常真人对战下，连续对战或者GameOver时，可以保存徽章有无升降级
  3.街机模式下，GameOver时，才会保存徽章有无升降级
  4.对于单次结算，如无法判断时，会另外根据‘刷卡exe根目录/wwwroot/data/player_badge_max_exps.json’(未全)
    里面写好的最大exp来粗略判断有无升降级...
  因为是实验功能，所以同时保留刷卡页可选择徽章(不显示玩家等级在选徽章选项里)  
```

## 截至当前版本 总功能 简述
刷卡及游戏内:
```
1.修正开卡刷卡，对战结果(街机|店内|店外)有限保存(包括等级经验/机体熟练度/导航员好感度等)
2.手柄，通信，对战UI，对战壁纸，机体姿势等对战高度相关的，未改动，未测试，暂无打算...
3.支持选ib新领航员，新bgm，新ib机体+修正几台机体的cost值+驾驶员皮肤
4.加载训练场新设置, 但是游戏内不提供保存..
5.加载偏好机体可配置觉醒和单独的歌曲
6.修正用户等级为1到999到无限
7.尝试支持徽章经验和升级，因为是实验功能，所以同时保留刷卡页可选择徽章(不显示玩家等级在选徽章选项里)
8.街机模式刷卡后可正常预先选难度5，stage通关后可中断再开
9.去掉刷卡页面的V觉（包括统计），C觉改为E觉，去掉新卡第2次进教学的提示
10.修复对战记录页面报错, 修复对战记录觉醒数不算全觉的问题
11.对战记录页面与原ob关卡页面对换顺序，这样刷卡后点右边按钮直接查看对战记录
12.因为ib不区分ui和战斗导航员，刷卡页面里ui导航员和战斗导航员选择后保持一致
13.游戏内支持快速启动加载和保存(暂不支持练习模式和训练场), 刷卡页面支持自定义快速启动
14.数据库文件回退到ob功能，回退后改名，可迁移到其他魔改ob系列刷卡..(会丢失一点点ib新数据)
```
自定义配置(server.json内有详细说明，设置后需要重启刷卡):
```
1.原ob的配置未改动，新增可指定数据库文件位置
2.刷卡时可选显示蓝色的‘PLv.プーストキャンペーン開催中!’，显示橙色的‘グルーブボイント 超ブースト中!’(游戏中均没实际效果)
3.自定义偏好机体最大上限, 默认12。刷卡页和游戏里同时能生效。
4.增加设置几个店外等级，店外(段位)样式(即蓝色,金色这些),甚至可显示Ex无限级后的位数(数值随机)
5.异常显示stage3和难度10+，不过不能连战，也不能中断再开...
6.试验功能：远程卡服，默认关闭，用于店外对战匹配到群服真人玩家。(wip群自有支持，建议不要开启该功能)
7.单人2v2随机人机-另类试验: 本地店内外..
```
