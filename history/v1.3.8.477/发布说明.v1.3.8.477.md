# v1.3.8.477 更新
```
1.修正非跨服‘custom match’的room同样都是相同code而不能正常组队的bug..
2.‘custom-match’的房间id改为由‘code，是否私房，组队类型等’判断生成，生成的id必须大于100，否则刷卡失败(如失败了请改code或其他配置)。
  同时(同款跨服)只有相同房间id才能被(match3服务)匹配到一齐对战，不同房间id不会匹配到...
3.修正’是否接受消息‘, 这个选项之前写反了..
4.对战记录页面和编辑页面顶部都加上一个互相跳转到的按钮
5.增加可配置定时清理(按每个卡号算)过多的历史记录，免得数据库文件过大
6.手柄页面加上’设置为键盘或者手柄‘和‘键位指令提示’选项, 其中对战中的键位提示不再跟训练场的同步..
  手柄如不起效，请检查下是否xbox或ps协议，如是了但依然无效请另找教程...
  注意：为加快刷卡时响应速度，这2个新字段并不存放在数据库手柄表中...
7.去掉team页面一些被废弃的以前ob旧选项
8.增加提供基于arm64架构(安卓)的stun，match3，刷卡镜像. 
  所有镜像在创建容器时, 均支持设置时区..
```
