# v1.2.7 更新
```
1.街机模式中断再开，再开之前的存档失效时机，改为打完stage第一个小关卡结算后失效。
  这样，每次再开后，stage的小关卡可能是不一样的，boss也可能不一样的...

2.内部代码优化。
  1.程序exe改名为‘ServerIbOnOver.exe’。
  2.‘/match’接口的相关代码还原回到ob. 
    server.json里自定义配置里，LocalMatchingConfigs处于关闭时，是使用‘/match’, 开启后使用‘/match2’。

3.stages.json增加了ib的2个新战斗场地+训练场+随机场地的信息

4.修复对战记录觉醒数不算全觉的问题。
  1.有时候看对战记录里，(英文)统计页里BurstCount=0，TotalBurstDamage却不为0，而且会发现时间线里的觉醒数目与这个BurstCount不一样，为什么？
  2.测试发现，原来这个BurstCount是来源于对战结算里面字段的(Burst)，不管店外店内，游戏提交的结算信息就是半觉醒数，全觉数不算入其中..
    对战结算还有一个字段叫ExBurstXrossNum，这个测试发现，是开了OL盾后觉醒数, 通常要么0要么1 (毕竟不可能在10s内连开2次觉醒吧..)
  3.目前临时，在界面显示时，用时间线的觉醒数(这个包含半觉和全觉)，作为BurstCount..

```
